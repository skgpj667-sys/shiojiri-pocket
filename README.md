# 🍇 しおじりPocket（Shiojiri Info Hub）

塩尻市の**最新ニュース、SNS投稿、公式ホームページ更新、防災・イベント情報**を、一つのスマートフォン画面で快適に閲覧・活用できるオールインワンWebポータルアプリです。

---

## 🌟 主な機能と特徴

### 1. 📱 モバイルファースト・洗練されたスマホUI
- **1画面ですべて完結**: スマホでの操作に最適化された直感的で美しいUIデザイン（桔梗ヶ原ワインレッド＆信州アルプスグリーンを基調としたモダンデザイン）。
- **PC・スマホ両対応**: PCブラウザではリアルなスマホモックアップフレームで体験可能。ワンクリックで「全画面表示」への切り替えも可能。
- **PWA対応**: スマホの「ホーム画面に追加」でネイティブアプリ同様に利用可能。

### 2. 🏛️ 塩尻市の最新情報をリアルタイム集約
- **塩尻市役所 公式HP更新情報**: 新着情報・重要なお知らせ・参加募集・行政手続きなどをRSS/スクレイピングで自動取得（400件以上の最新情報を常時更新）。
- **地域ニュース**: 信濃毎日新聞、市民タイムス、MGプレス、Yahoo!ニュース等の塩尻市関連速報。
- **公式SNS・コミュニティ**: 塩尻市公式X (@shiojiri_city)、塩尻市観光協会 (@tokimeki_shiojiri)、地域おこし協力隊等の最新SNSフィードを統合。
- **イベント＆観光**: 桔梗ヶ原ワイナリー、奈良井宿、木曽漆器、平出遺跡、ぶどう狩りなどのイベント情報。
- **防災・くらし**: 夜間休日当番医、林野火災・気象警報、生活応援券、地域振興バス「すてっぷくん」運行状況、ゴミ出しカレンダー。

### 3. 🔍 快適な検索・フィルタリング
- **カテゴリタブ切り替え**: 「すべて」「市役所HP」「ニュース」「公式SNS」「イベント」「防災・くらし」「保存済み」
- **インクリメンタル検索**: キーワードで即座に絞り込み。
- **人気タグチップス**: `#子育て` `#イベント` `#ワイン・グルメ` `#防災・安全` `#奈良井宿` `#生活応援券` `#すてっぷくん` `#休日当番医` などのワンタップ絞り込み。

### 4. ☀️ 塩尻市ピンポイント天気・速報ティッカー
- **リアルタイム気象データ**: 塩尻市の現在の気温、天気、降水確率、最高/最低気温、湿度、風速を表示（タップで詳細ポップアップ）。
- **速報ティッカー**: 緊急速報や注目イベントが上部に自動スクロール。

### 5. ❤️ インタラクション＆便利機能
- **ブックマーク保存**: 気になる記事をワンタップでお気に入り保存（端末内LocalStorageに永続化）。
- **いいね・リアクション**: 記事や投稿へのリアクション機能。
- **SNS共有**: ワンタップで記事URLをシェアまたはクリップボードコピー。
- **詳細リーダーモーダル**: アプリ内で概要・全文を確認し、ワンタップで公式サイトへジャンプ。
- **文字サイズ変更**: 「標準」「大」「特大」にワンクリックで切り替え可能（シニア・見やすさ配慮）。
- **ダークモード / ライトモード**: 昼夜問わず目に優しいテーマ切り替え。

## 🚀 起動方法

### 方法1: バッチファイルから起動（Windows推奨）
フォルダ内の `start.bat` をダブルクリックするだけで、自動的にサーバーが立ち上がりブラウザで開きます。

### 方法2: コマンドラインから起動
```powershell
cd C:\Users\ts141\.gemini\antigravity\scratch\shiojiri-info-hub
python -m uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

起動後、ブラウザで以下のURLを開きます：
👉 **http://localhost:8000** （同じWi-Fi内のスマホからは `http://<PCのローカルIP>:8000` で直接スマホ実機から閲覧可能）
